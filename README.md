## ✨ Características del Portfolio

- 🎨 **Diseño Moderno & Dark Mode:** Paleta cuidada en tonos oscuros con acentos neón en cyan y azul, tipografía Geist y efectos glassmorphism.
- ⚡ **Rendimiento Ultrarrápido:** Construido sobre Next.js 16 con Turbopack y componentes optimizados para tiempos de carga mínimos (~100 ms).
- 📱 **Totalmente Responsive:** Adaptación fluida a dispositivos móviles, tablets y monitores de escritorio.
- 📂 **Proyectos Reales con Filtros Dinámicos:** Muestra proyectos de código abierto con acceso directo a repositorios y demostraciones en vivo.
- 📄 **Descarga de CV:** Acceso directo a mi currículum vitae original en formato PDF.
- 🔍 **SEO & OpenGraph Optimizado:** Metadatos estructurados para una indexación correcta en buscadores y vista previa enriquecida al compartir en redes.

## 📁 Estructura del Código

```text
Portfolio/
├── public/                # Favicon, imágenes y CV en PDF
├── src/
│   ├── app/               # Rutas, layout raíz, estilos globales y fuentes
│   │   ├── layout.tsx     # Metadatos SEO, OpenGraph y configuración HTML
│   │   ├── page.tsx       # Ensamblado principal de secciones
│   │   └── globals.css    # Sistema de diseño, temas y utilidades
│   ├── components/        # Componentes modulares de interfaz
│   │   ├── Navbar.tsx     # Menú de navegación interactivo
│   │   ├── Hero.tsx       # Presentación y llamadas a la acción
│   │   ├── About.tsx      # Formación académica y metodología
│   │   ├── Skills.tsx     # Habilidades técnicas y blandas
│   │   ├── Projects.tsx   # Grilla de proyectos con filtrado
│   │   ├── Experience.tsx # Trayectoria laboral y operativa
│   │   ├── Contact.tsx    # Formulario y canales de contacto
│   │   └── Footer.tsx     # Pie de página y enlaces
│   ├── data/              # Datos desacoplados (CV y proyectos)
│   │   ├── cv-data.ts     # Perfil, experiencia, estudios y datos personales
│   │   └── projects.ts    # Listado de proyectos reales
│   └── types/             # Tipado e interfaces TypeScript
└── next.config.ts         # Configuración de Next.js
```

## Instalación y Ejecución Local
Si deseas correr este proyecto en tu entorno local:
# 1. Clonar el repositorio
git clone https://github.com/harahel-ayun/Portfolio-Harahel-Ayun.git
cd Portfolio-Harahel-Ayun

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev

Abre en tu navegador http://localhost:3000 para ver la aplicación.
